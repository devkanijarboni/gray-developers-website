03 / CERTIFICATION

Introducing PUDC.

Program, Prompt and User Development Certificate.

Gray Developers' proposed classification framework for AI tools used with game engines. PUDC levels describe planned capability tiers and special features. The program may later open to external developers at no charge.

PUDC is a Gray Developers initiative, not an independent industry accreditation.
