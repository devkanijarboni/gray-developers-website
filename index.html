02A / CERTIFICATIONGRAY DEVELOPERS STANDARD

FOR GAME ENGINE AI

Introducing
PUDC.

Program, Prompt and User Development Certificate.

PUDC is Gray Developers' proposed classification system for AI tools built for game engines. A level identifies an AI tool's assessed development capabilities and special features.

For now, this system is planned for Gray Developers' own products. Free certification for other developers' game-engine AI may open later, following the growth of APX AI.

Gray Developers also plans creator recognition for people who build games using its AI tools. That program is separate from AI capability classification. PUDC is not an independent industry accreditation.
