# Gray Developers — Original Design, V2 Content

This package preserves the original black-and-white Gray Developers website layout, original logo references, responsive design, and script. It adds ULTIMA pricing, PUDC, and planned projects.

## Uploading to your existing GitHub Pages repository

1. BACK UP the current repository by downloading its ZIP.
2. In the existing repository, replace ONLY `index.html`, `styles.css`, and `script.js` with the three files in this package.
3. Keep your existing `assets/gray-developers-logo.png` and `assets/favicon.png` exactly where they are; those original logo files were not part of the files you uploaded here.
4. Commit your changes and let GitHub Pages deploy. Refresh with Ctrl+Shift+R.

## Important

This is a static information website. It does not have a working AI integration, subscriptions, payments, or verification system. All future releases and pricing are labeled as plans. No personal contact email is included.

To preview offline with the original logo visible, put your existing GitHub `assets` folder next to `index.html`.
